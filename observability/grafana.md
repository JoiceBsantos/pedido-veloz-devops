# Grafana

O Grafana será utilizado para visualização das métricas coletadas pelo Prometheus.

## Objetivos

- monitorar disponibilidade dos microsserviços
- acompanhar métricas da aplicação
- visualizar saúde do ambiente
- apoiar observabilidade cloud-native

## Dashboards previstos

- API Gateway
- Pedidos Service
- Pagamentos Service
- Estoque Service
