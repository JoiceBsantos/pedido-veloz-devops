# Observabilidade

A arquitetura utiliza observabilidade para garantir:

- monitoramento contínuo
- confiabilidade
- análise de métricas
- visibilidade operacional

## Ferramentas

- Prometheus
- Grafana

## Métricas monitoradas

- disponibilidade dos serviços
- status da API
- tempo de resposta
- saúde dos microsserviços

## Benefícios

- identificação rápida de falhas
- suporte à escalabilidade
- melhoria da confiabilidade
- acompanhamento operacional
