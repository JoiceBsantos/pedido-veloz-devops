# Arquitetura do Projeto

## Modelo Arquitetural

O projeto utiliza arquitetura baseada em microsserviços.

## Componentes

- API Gateway
- Pedidos Service
- Pagamentos Service
- Estoque Service
- PostgreSQL

## Objetivos da Arquitetura

- escalabilidade
- desacoplamento
- modularidade
- automação
- observabilidade

## Tecnologias Utilizadas

- Node.js
- Docker
- Docker Compose
- Kubernetes
- GitHub Actions
- Terraform
- Prometheus
- Grafana

## Características Cloud-Native

- conteinerização
- orquestração
- infraestrutura como código
- observabilidade
- CI/CD
