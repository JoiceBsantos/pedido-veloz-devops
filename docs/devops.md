# Estratégia DevOps

## CI/CD

A automação de integração contínua é realizada utilizando GitHub Actions.

## Conteinerização

Os serviços utilizam Docker para padronização dos ambientes.

## Orquestração

A aplicação será orquestrada utilizando Kubernetes.

## Observabilidade

O ambiente utiliza Prometheus e Grafana para monitoramento.

## Infrastructure as Code

Terraform é utilizado para provisionamento declarativo da infraestrutura.
