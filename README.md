# Pedido Veloz

Projeto acadêmico de Cloud DevOps baseado em microsserviços.

## Arquitetura

- API Gateway
- Serviço de Pedidos
- Serviço de Pagamentos
- Serviço de Estoque
- PostgreSQL

## Tecnologias

- Docker
- Docker Compose
- Kubernetes
- GitHub Actions
- Terraform
- Prometheus
- Grafana

## Objetivo

Demonstrar uma arquitetura cloud-native com:
- conteinerização
- CI/CD
- observabilidade
- escalabilidade
- automação

## Observabilidade

O projeto utiliza:

- Prometheus
- Grafana

para monitoramento e observabilidade da arquitetura de microsserviços.

## Infrastructure as Code

O projeto utiliza Terraform para provisionamento e automação da infraestrutura Kubernetes.
